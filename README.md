# HUI · 引力场

为 hui.noxc.uk 制作的互动视觉主页。原生 HTML、CSS、Canvas 和 JavaScript，无构建步骤，无第三方运行依赖，不采集访客数据。

## 功能

- 引力、星云、流光三种粒子形态，平滑切换。
- 指针偏转、点击涟漪、时间流速、暂停和 PNG 导出。
- 手机适配、键盘可访问控制、系统减少动态效果设置。
- 页面不可见或滚动离开画面时停止绘制。

## 本地查看

直接打开 index.html，或使用任意静态文件服务器。

## 发布

将本目录部署为静态网站。GitHub Pages 使用 main 分支根目录。绑定域名前先完成 DNS 所有权验证，然后在 Pages 设置中添加自定义域名、在域名管理平台设置对应 CNAME，最后启用 HTTPS。

修改文字：index.html；修改样式：style.css；修改粒子与互动：app.js。
